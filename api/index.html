API reference

Supports

CategoricalInterventions.Span — Type
Span(lo, hi)
lo .. hi

Half-open support [lo, hi) with lo < hi. The start time is included and the stop time excluded, so adjacent spans partition time. Type \bbI<TAB> for the 𝕀 alias.

CategoricalInterventions.Instant — Type
Instant(t)

A single time point. Used for state pulses, which act at an instant rather than over an interval.

CategoricalInterventions.:.. — Type
lo .. hi

The span [lo, hi); the same as Span(lo, hi).

CategoricalInterventions.Interval — Function
Interval(start, stop)

Deprecated alias for Span, kept for v0.1 compatibility.

CategoricalInterventions.contains_time — Function
contains_time(support, t) -> Bool
t ∈ support

Is t in the support?

CategoricalInterventions.overlaps — Function
overlaps(a, b) -> Bool

Do two supports share a time?

CategoricalInterventions.intersection — Function
intersection(a, b) -> support or nothing

The common part of two supports, or nothing if they are disjoint.

CategoricalInterventions.endpoints — Function
endpoints(support)

The event times of a support: (lo, hi) for a span, (t,) for an instant.

Effects

CategoricalInterventions.Identity — Type
Identity()

The effect that does nothing. It is the unit of every algebra.

CategoricalInterventions.SetValue — Type
SetValue(value)

Absolute effect: replace the target value with value.

CategoricalInterventions.Add — Type
Add(delta)

Additive effect: x ↦ x + delta.

CategoricalInterventions.Scale — Type
Scale(factor)

Multiplicative effect: x ↦ x * factor.

CategoricalInterventions.CapAt — Type
CapAt(limit)

Upper-bound effect: x ↦ min(x, limit).

CategoricalInterventions.FloorAt — Type
FloorAt(limit)

Lower-bound effect: x ↦ max(x, limit).

CategoricalInterventions.MapEffect — Type
MapEffect(f, label=:custom)

Custom effect given by an explicit function. Combines only under Reject (as the sole effect) or an ordered policy.

CategoricalInterventions.AffineEffect — Type
AffineEffect(absolute, relative)

Normal form of the Affine algebra: an optional absolute assignment followed by a relative effect. Means "set to absolute (if present), then apply relative".

CategoricalInterventions.Transfer — Type
Transfer(to, amount)

State pulse that moves amount from the atom's target state to the state named to. A single atom that conserves the total by construction.

CategoricalInterventions.Flow — Type
Flow(to, rate)

State flow: a continuous transfer from the atom's target state to to at per-capita rate over the atom's span. Realised by augment, which turns it into a parameter interval on an augmented model.

CategoricalInterventions.apply_effect — Function
apply_effect(effect, value)

Apply an effect to a value.

Algebras

CategoricalInterventions.Reject — Type
Reject()

Default algebra. Two overlapping effects on the same target are a conflict unless one of them is the identity.

CategoricalInterventions.Multiplicative — Type
Multiplicative()

Overlapping Scale effects multiply.

CategoricalInterventions.Additive — Type
Additive()

Overlapping Add (and Transfer) effects add.

CategoricalInterventions.Cap — Type
Cap()

Overlapping CapAt effects take the tighter limit (min).

CategoricalInterventions.Floor — Type
Floor()

Overlapping FloorAt effects take the tighter limit (max).

CategoricalInterventions.Affine — Type
Affine(relative::AbstractPCM)

At most one absolute SetValue, combined with any number of relative effects from relative; means "set, then apply the relative effects". Two overlapping absolute assignments are a conflict. This is the default for rates in models built from AlgebraicPetri and StockFlow.

CategoricalInterventions.LatestWins — Type
LatestWins()

Ordered policy: the later atom in program order replaces the earlier one.

CategoricalInterventions.HighestPriority — Type
HighestPriority()

Ordered policy: the atom with the largest metadata[:priority] wins; ties go to the later atom in program order.

CategoricalInterventions.combine — Function
combine(algebra, e1, e2) -> effect or nothing

The partial product of a PCM. nothing means the pair does not combine.

Targets, atoms, programs

CategoricalInterventions.TargetKind — Type
TargetKind

The kind of a target: Parameter, State, Process, or Observation. Parameter-like kinds are interval effects on the schedule; State targets take pulses and flows.

CategoricalInterventions.Parameter — Constant

Target kind for model parameters or rates.

CategoricalInterventions.State — Constant

Target kind for state variables. State interventions are pulses or flows.

CategoricalInterventions.Process — Constant

Target kind for process-level quantities; treated like parameters.

CategoricalInterventions.Observation — Constant

Target kind for observation-level quantities; treated like parameters.

CategoricalInterventions.Target — Type
Target(name; kind=Parameter)

What an intervention changes: a named parameter, state, process, or observation. Identity is (name, kind); the value type and combination algebra live on the TargetSpace of a model, not on the target.

CategoricalInterventions.TargetSpec — Type
TargetSpec(; value_type=Any, algebra=Reject())

Per-target declaration: the value type enforced on absolute effects and results, and the algebra used to combine overlapping effects.

CategoricalInterventions.TargetSpace — Type
TargetSpace(; default=Reject())

The table of declared targets of a model. Undeclared targets fall back to the default algebra and value type Any.

CategoricalInterventions.declare! — Function
declare!(space, target, algebra; value_type=Any)

Declare (or redeclare) the algebra and value type of a target.

declare!(model, name, algebra; kind=Parameter, value_type=Float64)

Change the algebra of one target of a model.

CategoricalInterventions.algebra — Function
algebra(space_or_program, target)

The combination algebra declared for a target (the default if undeclared).

CategoricalInterventions.value_type — Function
value_type(space, target)

The value type declared for a target (Any if undeclared).

CategoricalInterventions.Atom — Type
Atom(id, target, support, effect; metadata=Dict())

A local, typed, temporal edit: change target by effect on support.

Well-formedness: parameter-like targets take spans; state targets take an Instant with a pulse effect (SetValue, Add, Transfer) or a Span with a Flow.

CategoricalInterventions.InterventionAtom — Function
InterventionAtom(id, target, support, effect; metadata)

Deprecated v0.1 constructor. A Span on a State target is converted to an Instant at the span start.

CategoricalInterventions.Program — Type
Program(atoms...; space=TargetSpace())

A finite list of atoms together with the declaration table of their targets. Order matters only under ordered policies.

CategoricalInterventions.expand — Function
expand(atom) -> Vector{Pair{Target,AbstractEffect}}

The per-target effects an atom contributes. A Transfer contributes a removal on its own target and an addition on the destination; a Flow contributes nothing until the model is augmented.

CategoricalInterventions.active — Function
active(program, t) -> Vector{Atom}

Atoms whose support contains t.

CategoricalInterventions.Conflict — Type
Conflict

A same-target overlap that the target's algebra cannot combine. required is an algebra that would resolve it.

CategoricalInterventions.InterventionConflictError — Type
InterventionConflictError(conflicts)

Thrown when a program has unresolved conflicts. Inspect .conflicts.

CategoricalInterventions.conflicts — Function
conflicts(program) -> Vector{Conflict}

All pairs of atoms that overlap in time, touch the same target, and whose effects the target's algebra cannot combine. For the shipped PCMs, pairwise combinability is equivalent to conflict-freeness (Lean: conflictFree_of_pairwise).

CategoricalInterventions.validate — Function
validate(program) -> Bool

true when the program has no conflicts.

CategoricalInterventions.compose — Function
compose(programs...; check=true)
p ⊕ q

Compose programs: concatenate atoms and merge declaration tables. With check=true a conflicting composite throws InterventionConflictError. Associative with the empty program as identity (Lean: compose_assoc).

CategoricalInterventions.restrict — Function
restrict(program, lo, hi) -> Program

The atoms meeting the closed window [lo, hi], with spans clipped to [lo, hi). The restrict operation of the design note.

CategoricalInterventions.shift — Function
shift(support, δ)

Translate a support later in time by δ.

shift(program, δ) -> Program

Translate every support later by δ (earlier for negative δ). Shifting commutes with composition and with the action on schedules, and preserves conflict-freeness (Lean: shift_append, apply_shift, conflictFree_shift).

CategoricalInterventions.extent — Function
extent(program) -> (start, stop)

The earliest start and latest end of any support; nothing for the empty program. An instant contributes its time to both.

CategoricalInterventions.seq — Function
seq(p, q; gap=0) -> Program
p ⋙ q

Sequential composition: q shifted so that it begins when p ends (plus gap), composed with p. Equal to p ⊕ shift(q, extent(p)[2] + gap - extent(q)[1]), so it inherits the laws of ⊕ and shift. With an empty p or q the other program is returned unchanged.

CategoricalInterventions.:⋙ — Function
p ⋙ q

Sequential composition; the same as seq(p, q). Type \ggg<TAB>.

CategoricalInterventions.Epoch — Type
Epoch

A maximal span on which the set of active span atoms is constant. Records the active atoms, their combined effect per target (nothing where the algebra fails), and the pulses that fall inside the span.

CategoricalInterventions.epochs — Function
epochs(program; check=true) -> Vector{Epoch}

The common refinement of all span supports. Adding atoms only refines this partition (Lean: epochs_refine). With check=false, conflicting targets are recorded with effect nothing instead of throwing.

CategoricalInterventions.active_effects — Function
active_effects(program, t; check=true) -> Dict{Target, effect}

Combined effect per target at time t, over all active atoms (spans and instants).

CategoricalInterventions.boundaries — Function
boundaries(program)

The sorted span endpoints of a program; consecutive pairs are the epochs.

Narratives

CategoricalInterventions.persistent — Function
persistent(program)

The persistent narrative: A(lo, hi) is the vector of atoms whose support contains all of [lo, hi]; A(t) is the atoms active at t. Satisfies A[a,b] = A[a,p] ∩ A[p,b] (Lean: persistent_glue).

CategoricalInterventions.cumulative — Function
cumulative(program)

The cumulative narrative: C(lo, hi) is the vector of atoms whose support meets [lo, hi]; C(t) is the atoms active at t. Satisfies C[a,b] = C[a,p] ∪ C[p,b] and C[a,p] ∩ C[p,b] = C[p,p] (Lean: cumulative_union, cumulative_inter_eq_point).

Semantics

CategoricalInterventions.apply — Function
apply(program, baseline::Dict{Symbol}) -> Vector{EpochValues}

Apply a program to scalar baseline values, one result per epoch. Span atoms only; pulses are events, not schedule edits.

apply(program, baseline::Dict{Symbol,<:AbstractVector}, times) -> Dict

Apply a program pointwise to time-indexed schedules. State pulses at a grid time are applied to that grid point's value (the pre-update convention) when the state's schedule is supplied, and ignored otherwise.

CategoricalInterventions.EpochValues — Type
EpochValues

Values induced on one epoch by applying a program to a scalar baseline.

CategoricalInterventions.sample — Function
sample(program, grid::AbstractRange) -> Program

Pull a program back along the grid map k ↦ grid[k]: each span [a, b) becomes the span of grid indices k with a ≤ grid[k] < b, and each instant becomes the index of the matching grid point (an instant off the grid is dropped with a warning). Applying the sampled program at indices agrees with applying the original at grid values (Lean: apply_pullback, grid_preimage_span).

Models

CategoricalInterventions.Model — Type
Model(dynamics; parameters, states, kind=:continuous, invariants=[],
      rate_algebra=Affine(Multiplicative()), state_algebra=Additive(),
      value_type=Float64)

A simulation model with declared targets. parameters and states are vectors of names (labelled containers) or dictionaries from names to positions. Rates default to the set-then-scale algebra and states to the additive algebra.

CategoricalInterventions.Indexing — Type
Indexing(; parameters, states)

Selectors locating each target in integrator.p and integrator.u. A vector of names uses the names themselves (for labelled arrays); a dictionary maps names to positions or other selectors. PetriIndexing is the v0.1 name.

CategoricalInterventions.Conserved — Type
Conserved(states)

The sum of the named states is preserved by every pulse.

CategoricalInterventions.Nonnegative — Type
Nonnegative(states)

The named states stay non-negative after every pulse.

CategoricalInterventions.InvariantViolation — Type
InvariantViolation

Thrown when a pulse breaks one of the model's invariants.

CategoricalInterventions.program — Function
program(model, atoms...)

A program whose declaration table is the model's.

CategoricalInterventions.parameters — Function
parameters(model)

Names of the model's parameter-like targets.

CategoricalInterventions.states — Function
states(model)

Names of the model's state targets.

CategoricalInterventions.targets — Function
targets(space_or_model)

The declared targets.

CategoricalInterventions.check_targets — Function
check_targets(program, model)

Every target the program touches must have a selector in the model.

CategoricalInterventions.augment — Function
augment(model, program) -> (model=..., program=..., extend=p0 -> p0′)

Realise every Flow atom by adding a process to the model. Each flow becomes a parameter interval that sets the new rate on the flow's span; the new rate has baseline zero, so outside the span the augmented model equals the original (Lean: augment_restrict).

CategoricalInterventions.augment_flow — Function
augment_flow(model, from, to, rate_name) -> Model

Return a model with an added process moving from to to at the per-capita rate named rate_name, whose baseline value is zero. AlgebraicPetri models get a new transition; models whose dynamics is a function (hand-written ODEs, StockFlow vector fields, discrete maps) get a wrapped function that subtracts rate * u[from] from from and adds it to to; AlgebraicDynamics systems are converted to a function first. Positional parameter vectors receive the new rate at the next index, so every existing parameter must be declared. Extensions specialise _augment_flow(::Val{source}, ...).

CategoricalInterventions.extend_parameters — Function
extend_parameters(model, p0, additions::AbstractVector{<:Pair{Symbol}})

Return a parameter container like p0 extended with the given named entries, in order. Plain vectors are appended to; labelled containers gain labels.

CategoricalInterventions.target_map — Function
target_map(morphism) -> Dict{Target,Target}

Extension hook: the map of targets induced by a model morphism.

CategoricalInterventions.strata — Function
strata(model_object) -> Dict{Target,Any}

Extension hook: the stratum label of each stratified target.

CategoricalInterventions.stratify — Function
stratify(base, strata, types, base_types, strata_types)

Extension hook: stratify a base model by a strata model over a type system, returning the stratified model object and the two projections.

CategoricalInterventions.typed_by — Function
typed_by(net, types, transition_types)

Extension hook: the typing morphism of a net into a type system.

CategoricalInterventions.dom — Function
dom(morphism)

Domain of a model morphism.

CategoricalInterventions.codom — Function
codom(morphism)

Transport

CategoricalInterventions.pushforward — Function
pushforward(program, f; space=nothing) -> Program

Rename every atom's target along f, a Dict{Target,Target}, Dict{Symbol,Symbol}, or function on targets. Targets not in the map are kept. If f merges targets, new conflicts may appear and are reported. The new declaration table is space if given, else the old table transported along f.

CategoricalInterventions.lift — Function
lift(program, π; strata=Dict(), space=nothing) -> Program

Pull a program back along a projection π::Dict{Target,Target} from the targets of a stratified model to the targets of its base. Each atom on base target j becomes one atom on each j′ with π[j′] == j, with id suffixed by the new target name. A Transfer needs strata, a Dict{Target,Any} naming the stratum of each stratified target, so the destination is matched within the same stratum. Undeclared new targets inherit their base target's declaration.

lift(program, π::Dict{Symbol,Symbol}; kinds...)

Convenience: a projection given on names; kinds are taken from the program's atoms.

CategoricalInterventions.lift_along — Function
lift_along(program, π; kwargs...)

The same as lift. Use it when Catlab is also loaded, since Catlab exports a different lift.

CategoricalInterventions.fibres — Function
fibres(π) -> Dict{Target, Vector{Target}}

Group the domain of a projection π::Dict{Target,Target} by image.

CategoricalInterventions.@interventions — Macro
@interventions model begin
    lockdown    = scale(:inf, 0.5; during=5..25)
    vaccination = transfer(:S => :R, 50; at=15)
end

Build a Program on the model's targets, using each assignment's name as the atom id. model may be a Model, a TargetSpace, or another Program. Bare expressions (no name =) get automatic ids.

Inference

CategoricalInterventions.infer — Function
infer(baseline, observed, times; space, kind=Parameter, atol=1e-10) -> Program

baseline and observed are Dict{Symbol,<:AbstractVector} on the grid times (a range or sorted vector). Returns one atom per maximal run where the observed value differs from baseline by a constant ratio or difference. The last span ends one grid step after the last grid time.

Queries

NarrativeWindow(targets, times)

The ambient graph of a finite window: one vertex per (target, time) and one edge per (target, unit interval).

The program's target-level persistent narrative on the window: vertex (j, k) iff some atom on j is active at tₖ; edge (j, k) iff some atom on j covers [tₖ, tₖ₊₁].

Is the target under intervention at some time in [tₖ, tₖ₊₁]? For the subobject of a program this is the cumulative narrative on the unit interval; it is read off the window at the resolution of the grid (either endpoint, or the edge).
