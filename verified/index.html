Verified properties

Every claim the documentation makes about the algebra of programs, with the Lean theorem that proves it and the Julia test that exercises it. The Lean sources live in proofs/ and build with make build (Lean 4.30.0, Mathlib v4.30.0). This page is generated by docs/ledger.jl, which fails the build if a listed theorem is absent from the sources.

Lean verifies the algebra of programs, their action on schedules, and the lowering algorithm; it does not verify the ODE solver or Catlab.
